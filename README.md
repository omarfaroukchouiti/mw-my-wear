# MW — My Wear

استوديو ملابس رقمي جزائري: تصميم القطعة في المتصفح، الطلب، ثم تتبّع الطلب.
الواجهة عربية أولاً (RTL) مع الإنجليزية، ووضع فاتح/داكن يتبع تفضيل النظام.

- **التقنيات:** Next.js 16.4 · React 19.3 · TypeScript · Tailwind CSS 4 · Fabric.js 7 · Supabase
- **التوثيق الكامل:** [docs/README-DETAILED.md](docs/README-DETAILED.md)
- **الأصول المطلوبة من المالك:** [docs/OWNER-CONTENT.md](docs/OWNER-CONTENT.md)

## التشغيل محلياً

يتطلب Node.js 20 أو أحدث.

```bash
npm install
cp .env.example .env.local        # Windows: Copy-Item .env.example .env.local
npm run dev
```

املأ `.env.local` بقيمك، ثم افتح <http://localhost:3000> (يحوّل تلقائياً إلى `/ar`).

بدون Supabase تُحفظ الطلبات محلياً في `.data/` — للتطوير فقط، لأن الاستضافات
الخادمية لا تحتفظ بالملفات بين الطلبات.

## متغيرات البيئة

معظم المتغيرات **خادمية فقط**. المتغير العام الوحيد هو `NEXT_PUBLIC_SITE_URL` لأنه يظهر في canonical وOpen Graph:

| المتغير | الغرض |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | اختياري — اتركه فارغاً على Vercel لاستخدام دومين المشروع المجاني؛ اضبطه فقط عند ربط دومين مخصص |
| `SITE_URL` | اسم قديم اختياري، ما زال مدعوماً |
| `SUPABASE_URL` | رابط مشروع Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | مفتاح الخدمة الخادمي (يتجاوز RLS — لا يُكشف أبداً) |
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة (12 حرفاً على الأقل) |
| `ADMIN_SECRET` | توقيع جلسة الإدارة (32 حرفاً عشوائياً على الأقل) |
| `ADMIN_SESSION_HOURS` | مدة الجلسة بالساعات (اختياري، الافتراضي 12) |
| `UPSTASH_REDIS_REST_*` | تحديد معدل الطلبات الموزّع (اختياري لكن موصى به على Vercel) |

`.env.local` مستثنى من Git. لا ترفع أي ملف بيئة إلى المستودع.

## الأوامر

```bash
npm run dev        # تطوير
npm run build      # بناء إنتاجي
npm run start      # تشغيل نسخة الإنتاج
npm run verify:sql # فحص مخطط قاعدة البيانات
```

## البنية المختصرة

```
src/
  app/[locale]/     كل الصفحات تحت /ar أو /en (الرئيسية، المنتجات، الاستوديو، …)
  app/api/          مسارات الطلبات والإدارة
  components/       مكوّنات الواجهة والاستوديو
  lib/              البيانات، i18n، إعدادات الموقع وSEO
public/             الشعار الرسمي، فيديو الاستوديو، الصور
supabase/           المخطط والترحيلات
scripts/            سكربتات مساعدة
```

## النشر على Vercel

1. استورد المستودع في Vercel؛ سيكتشف Next.js تلقائياً.
2. أضف متغيرات البيئة نفسها في **Project → Settings → Environment Variables**.
3. تأكد من نجاح `npm run build`.
4. بعد ربط الدومين، اضبط `NEXT_PUBLIC_SITE_URL` على الأصل النهائي وأعد النشر.

## الهوية والوضع الداكن

- الشعار الرسمي `public/mw-logo.svg` مستخدم كما سلّمه المالك (**بدون أي تعديل على بايتاته**)، ويُعرض على لوحة حبر `#111111` لأنه فاتح اللون.
- أيقونة التبويب `src/app/icon.svg` تعرض الملف الرسمي نفسه مرجعاً، دون نسخ مساراته أو إعادة تلوينه.
- الثيم يعتمد `data-theme` على `<html>` مع متغيرات CSS؛ أول زيارة تتبع `prefers-color-scheme`، واختيار المستخدم يُحفظ في `localStorage` تحت `mw-theme`.
- حاويات صور القطع تستخدم خلفية معرض فاتحة في الوضعين (`--color-stage`) لإبقاء الرسومات الداكنة واضحة.
- حسابات التواصل (Instagram/TikTok/Facebook) معرّفة في `src/lib/site.ts`؛ رابط فيسبوك الرسمي مُدخل ويُستخدم أيضاً في `sameAs` بالبيانات المهيكلة.
