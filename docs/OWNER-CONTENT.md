# ما أحتاجه منك — الحسابات والتعديلات

آخر تحديث: 5 نوفمبر 2026

هذا الملف هو قائمة الانتظار القصيرة: كل ما يخصّ **بياناتك الحقيقية** و**تعديلات التصميم**.
الكود جاهز لاستقبالها، ولا يحتاج أي تعديل بنيوي.

## 1. بيانات التواصل (نقطة تعديل واحدة)

الملف: `src/lib/site.ts`

```ts
export const site = {
  email: "…",
  logo: "/mw-logo.svg", // الشعار الرسمي المستلم — لا تغيّر الملف نفسه
  social: [
    { label: "Instagram", href: "…" },
    { label: "TikTok", href: "…" },
    { label: "Facebook", href: "https://www.facebook.com/people/MyWear-MW/61596388254225/" },
  ],
};
```

الحالة: **مكتمل** — البريد والحسابات الحقيقية مُدخلة، بما فيها Facebook.

| العنصر | القيمة المعتمدة |
|---|---|
| البريد الإلكتروني | `mywear.official@gmail.com` — يُفتح عبر Gmail compose في تبويب جديد |
| Instagram | `https://www.instagram.com/mywear.design` |
| TikTok | `https://www.tiktok.com/@mywear.design` |
| Facebook | `https://www.facebook.com/people/MyWear-MW/61596388254225/` |

> لا يوجد أيقونة YouTube ولا صفحة له، بناءً على طلبك.
>
> عنوان البريد تحت الأيقونات يبقى نصاً، والضغط عليه يفتح نافذة رسالة جديدة في Gmail (`https://mail.google.com/mail/?view=cm&to=…`) في تبويب جديد مع `rel="noopener noreferrer"`.

> الرابط أعلاه هو الرابط الثابت للصفحة، استُخرج من رابط المشاركة الذي أرسلته بعد إزالة معاملات التتبّع (`?rdid`, `share_url`, `_rdc`). رابط المشاركة نفسه يعمل أيضاً، لكن الثابت أوضح لمحركات البحث وأدوم.

> لا تُضاف أرقام هواتف أو عناوين أو أرقام سجل تجاري إلا إذا أعطيتني القيمة الحقيقية بنفسك.
> لن أخترع أي معلومة عمل.

## 2. التصميم

نُفّذت الواجهة الجديدة وفق وصفك: أبيض/أسود/رمادي، RTL افتراضي، صفحة رئيسية من عشرة أقسام، بحث فعلي، تصفية مجموعات، وشريط مجتمع أفقي. ما يبقى بصرياً مربوط بالأصول الناقصة أعلاه (الصورة المرجعية وصور المنتجات).

أخبرني تحديداً بما تريد تغييره، مثلاً:

- الصفحة الرئيسية: ترتيب الأقسام، الصور، النصوص التعريفية.
- الألوان والخطوط: هل تبقى الهوية أبيض/أسود أم تريد لمسة لون؟
- المتجر وبطاقة المنتج: عدد الأعمدة، حجم الصور، طريقة العرض.
- الاستوديو: ترتيب الأدوات، الأزرار، النصوص التوضيحية.
- الصفحات القانونية: النصوص الحالية مسودّة كاملة في `src/lib/i18n.ts` — راجعها وأخبرني بأي تعديل.

كل نص جديد يُضاف بالعربية والإنجليزية معاً في `src/lib/i18n.ts`.

### دليل المقاسات

أُنشئت صفحة `/{ar|en}/sizes` وربطها بالفوتر وبصفحة المنتج. الجدول في `src/lib/sizes.ts` يعتمد الوزن (كلغ) والطول (سم) كما في مرجعك:
S 45–55 / 150–164 · M 56–70 / 164–173 · L 70–85 / 174–179 · XL 85+ / 180+.

## 3. الهجرة الوحيدة المعلّقة

الملف: `supabase/migrations/004_delivery_rates.sql`

الحالة: **مطبّقة ومختبرة** (4 نوفمبر 2026) — الجدول موجود، والحفظ من اللوحة يعمل، وتعديل الصف يُحدّث `updated_at` تلقائياً.

ما تبقّى عليك: إدخال **تعريفة شركة التوصيل الحقيقية** من **لوحة الإدارة → أسعار التوصيل** (`/ar/admin/delivery`). أسعار الإطلاق الحالية (500–1300 د.ج) **عناصر نائبة**، وليست تعريفة متعاقد عليها.

## 4. مراجعة النصوص القانونية (مسودّة)

الصفحات: `/{ar|en}/shipping`، `/privacy`، `/terms`، `/faq`. النصوص في `src/lib/i18n.ts` تحت `shipping` و`privacy` و`terms` و`faq`.

تحتاج إقرارك على هذه النقاط تحديداً:

| البند | الحالي | ما تحتاجه منك |
|---|---|---|
| مدة الإرجاع للقطع المعيبة | **48 ساعة من الاستلام** مع صور ورقم الطلب | هل توافق؟ أو تريد مدة أطول؟ |
| الحالات المقبولة للإرجاع | عيب أو اختلاف عن التصميم المؤكد فقط | هل تريد إضافة حالة أخرى؟ |
| التعويض | إعادة التصنيع أو إعادة القيمة | أيّهما تفضّل كخيار أول؟ |
| الإلغاء | قبل بدء الإنتاج فقط | هل توافق؟ |
| حدود المسؤولية | قيمة القطعة أو إعادة تصنيعها | صياغة قانونية نهائية إن كان لديك محامٍ |
| المحتوى المرفوع | المالك مسؤول عن حقوق الصور والنصوص | هل توافق؟ |

> هذه مسودّة وليست استشارة قانونية. المالك مسؤول عن اعتماد النص النهائي.

## 6. بعد استلام البيانات

1. أُحدّث `src/lib/site.ts`.
2. أنفّذ تعديلات التصميم التي وصفتها.
3. أتحقق: `tsc --noEmit`، `npm run build`، ثم فحص الصفحات فعلياً في المتصفح (عربي/إنجليزي، جوال/سطح مكتب).
4. أُعيد لك تقريراً بما تغيّر وما بقي.
